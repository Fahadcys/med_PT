1. Defining the Objective: Attack Simulation, Not Compromise١. التعريف: محاكاة هجوم وليس اختراقاً

Penetration testing is a controlled, authorized simulation of an attack. It tests system security using real attack techniques, but never compromises or damages the target.الاختبار الاختراقي محاكاة منضبطة ومصرّحة لهجوم. يختبر أمان النظام بتقنيات هجوم حقيقية، لكنه لا يخترق الهدف ولا يتلفه.

MethodالطريقةUnstructured, opportunistic breaches.اختراقات عشوائية انتهازية.Formal process rooted in standard project management.عملية رسمية مبنية على إدارة المشاريع القياسية.

Key pointsنقاط مهمة

  • Penetration testing and hacking are not synonymous.الاختبار الاختراقي والهاكينج ليسا شيئاً واحداً.
  • A pentest always starts with a contract and formal authorization.الاختبار يبدأ دائماً بعقد وتصريح رسمي.

2. The Security Assessment Spectrum٢. طيف التقييم الأمني

AUDITS

Auditsالتدقيق

Focus: compliance and documentation.التركيز: الامتثال والتوثيق.

Process: passive. Reviews incident response, disaster recovery, and system logs (firewall, IDS).الأسلوب: سلبي (Passive). يراجع الاستجابة للحوادث والتعافي من الكوارث وسجلات الأنظمة.

VULNERABILITY SCANS

Vulnerability Scansفحص الثغرات

Focus: detection of known flaws.التركيز: اكتشاف الثغرات المعروفة.

Process: automated. Identifies CVEs as a baseline and helps select targets, but is not the test itself.الأسلوب: آلي. يحدد الـ CVEs كخط أساس ويساعد في اختيار الأهداف، لكنه ليس الاختبار نفسه.

PENETRATION TESTING

Penetration Testingالاختبار الاختراقي

Focus: flaw exploitation.التركيز: استغلال الثغرات.

Process: active. Manual use of hacking techniques to penetrate the system.الأسلوب: فعّال (Active). استخدام يدوي لتقنيات الاختراق.

Key pointsنقاط مهمة

  • Audit = passive, scan = automated, pentest = active and manual.التدقيق = سلبي، الفحص = آلي، الاختبار الاختراقي = فعّال ويدوي.
  • A scan finds the flaw; a pentest exploits it.الفحص يكتشف الثغرة، والاختبار الاختراقي يستغلها.

5. The Three Pillars of Ethical Engagement٥. الركائز الثلاث للالتزام الأخلاقي

MANDATE_01

Absolute Confidentialityالسرية المطلقة

The tester inherently views highly sensitive private data. All client information must be protected, regardless of a formal NDA.المختبر يطّلع بطبيعة عمله على بيانات خاصة حساسة جداً. يجب حماية كل معلومات العميل حتى لو لم يوجد NDA رسمي.

MANDATE_02

Honest Capability ("Keep in Your Lane")الصدق في القدرات

High market demand tempts exaggeration. Ethical testers are transparent about their skill sets (e.g., admitting a lack of social engineering experience).الطلب العالي في السوق يغري بالمبالغة. المختبر الأخلاقي شفاف بشأن مهاراته (مثلاً يعترف بنقص خبرته في الهندسة الاجتماعية).

MANDATE_03

Zero-Disruption ("If You Break It, You Bought It")عدم التعطيل

Roles and testing conditions must be explicitly contracted. Testers must minimize operational disruption, using backup systems for sensitive targets when necessary.يجب تحديد الأدوار وظروف الاختبار صراحةً في العقد. على المختبر تقليل التعطيل التشغيلي واستخدام أنظمة احتياطية للأهداف الحساسة عند الحاجة.

1. Penetration Testing (Pentest)١. الاختبار الاختراقي

Pentesting involves simulating real attacks to assess the risk associated with potential security breaches.الاختبار الاختراقي يعني محاكاة هجمات حقيقية لتقييم المخاطر المرتبطة بالاختراقات الأمنية المحتملة.

On a pentest (as opposed to a vulnerability assessment), the testers not only discover vulnerabilities but also exploit them, where possible.في الـ pentest (بخلاف الـ vulnerability assessment) المختبرون لا يكتفون باكتشاف الثغرات بل يستغلونها متى أمكن.

  • The "get out of jail free" card is your written authorization. If the target is hosted by a third party, verify the client has formal approval from that party.بطاقة "get out of jail free" هي تصريحك المكتوب. إذا كان الهدف مستضافاً عند طرف ثالث، تأكد أن العميل حاصل على موافقة رسمية من ذلك الطرف.

DNS Zone Transfersنقل منطقة الـ DNS

Many system administrators set up DNS zone transfers insecurely, so anyone can download all DNS records for a domain. Example: zoneedit.com. From the records we can guess roles, e.g., mail2.zoneedit.com is probably a mail server, so we check ports 25 (SMTP) and 110 (POP3).كثير من مدراء الأنظمة يضبطون الـ zone transfer بشكل غير آمن، فأي شخص يقدر ينزّل كل سجلات الـ DNS للدومين. من السجلات نخمّن الأدوار، مثلاً mail2 غالباً سيرفر بريد فنفحص المنفذين 25 (SMTP) و110 (POP3).

Key pointsنقاط مهمة

  • Services exposed for remote access (web, mail, VPN, SSH, FTP) are common attack surfaces; without two-factor authentication, guessing valid credentials can be simple.الخدمات المكشوفة للوصول عن بعد (ويب، بريد، VPN، SSH، FTP) أسطح هجوم شائعة، وبدون مصادقة ثنائية قد يسهل تخمين بيانات الدخول.
  • Emails found (e.g., with theHarvester) help guess usernames and passwords.الإيميلات المكتشفة (مثلاً بـ theHarvester) تساعد في تخمين أسماء المستخدمين وكلمات المرور.

4. Rootkits Inside the OS٤. الـ Rootkits داخل نظام التشغيل

USERLAND

Performs: replaces login, sshd, passwd.ينفّذ: يستبدل login وsshd وpasswd.

Hides activity: ps, netstat, ls, find, du.يخفي النشاط: أوامر ps وnetstat وls وfind وdu.

KERNEL

Kernel rootkitروت كت مستوى النواة

The kernel handles process management, file access, memory management and network management. The rootkit subverts it to hide processes, files and network traffic.النواة تدير العمليات والملفات والذاكرة والشبكة. الـ rootkit يخترقها ليخفي العمليات والملفات وحركة الشبكة.

Techniques: kernel patch, Loadable Kernel Module (LKM), kernel memory patching (/dev/kmem).التقنيات: تعديل النواة، وحدة نواة قابلة للتحميل (LKM)، وتعديل ذاكرة النواة (/dev/kmem).

MBR / BOOTKIT

Bootkitبوت كت

Can avoid all OS protections, because the OS assumes the system was in a trusted state when the boot loader took control.يتجاوز كل حمايات النظام، لأن النظام يفترض أن الجهاز كان في حالة موثوقة لحظة استلام الـ boot loader.

Vboot: works on every Windows (Vista, 7), about 3 KB, bypasses checks by letting them run and then patching in flight, and communicates via ping.Vboot: يعمل على كل ويندوز (Vista، 7)، حجمه حوالي 3 كيلوبايت، يتجاوز الفحوصات بتركها تشتغل ثم التعديل أثناء التنفيذ، ويتواصل عبر ping.

HYPERVISOR

Hypervisor rootkitروت كت الـ Hypervisor

Sits between the hardware and the target OS as a virtual machine monitor, so the original OS and its apps run unaware inside a VM.يجلس بين العتاد ونظام التشغيل الهدف كمراقب أجهزة افتراضية، فيشتغل النظام الأصلي وتطبيقاته داخل VM وهم ما يدرون.

Cohen's impossibility resultنتيجة الاستحالة عند Cohen

  • It is not possible to build a perfect virus/malware detector.لا يمكن بناء كاشف مثالي للفيروسات.
  • Diagonal argument: let P be a perfect detector and V a virus that can call P. If P(V) = true, V halts; if P(V) = false, V spreads. Either way P is wrong.البرهان القطري: لنفرض أن P كاشف مثالي وV فيروس يستطيع استدعاء P. إذا P(V) = true يتوقف V، وإذا false ينتشر. في الحالتين P يخطئ.

Consequencesالعواقب

ATM systems unavailable, phone network overloaded (no 911), 5 DNS root servers down, planes delayed.تعطل أجهزة الصراف، وازدحام شبكة الهاتف (بلا طوارئ 911)، وسقوط 5 من سيرفرات DNS الجذرية، وتأخر الطائرات.

Detection and defenseالكشف والدفاع

  • Honeyfarms: collections of honeypots fed by a network telescope. Any outbound connection from the honeyfarm means a worm. A signature is distilled from the inbound/outbound traffic.Honeyfarms: مجموعات honeypots تغذيها network telescope. أي اتصال صادر من الـ honeyfarm يعني دودة. ويُستخرج توقيع من الحركة الواردة والصادرة.
  • If the telescope covers N addresses, detection is expected when the worm has infected 1/N of the population.لو غطّى الـ telescope عدد N من العناوين، يُتوقع الكشف عندما تصيب الدودة 1/N من المجتمع.
  • Scan suppressors: network elements that block traffic from hosts making failed connection attempts to too many other hosts.Scan suppressors: عناصر شبكية تحجب حركة الأجهزة التي تفشل في الاتصال بعدد كبير من الأجهزة الأخرى.
  • Writing a signature takes 5 minutes to several weeks, plus several hours or more of testing.كتابة التوقيع تأخذ من 5 دقائق إلى عدة أسابيع، مع ساعات أو أكثر للاختبار.

Signature inference and content siftingاستنتاج التوقيع والـ content sifting

The challenge is learning a content signature for each new worm automatically, potentially in under a second (Autograph, Automated Worm Fingerprinting). Signatures then enable content filtering.التحدي هو تعلّم توقيع المحتوى لكل دودة جديدة تلقائياً، وربما في أقل من ثانية. ثم تُستخدم التواقيع في تصفية المحتوى.

Content siftingContent sifting

  • Assume a (relatively) unique invariant bitstring W exists across all instances of a worm.نفترض وجود سلسلة بتات ثابتة فريدة نسبياً W في كل نسخ الدودة.
  • Content prevalence: W is more common in traffic than other bitstrings of the same length.انتشار المحتوى: W أكثر شيوعاً في الحركة من سلاسل أخرى بنفس الطول.
  • Address dispersion: the packets containing W address a disproportionate number of distinct sources and destinations.تشتت العناوين: الحزم التي تحتوي W تخاطب عدداً كبيراً من المصادر والوجهات المختلفة.
  • Find W with high prevalence and high dispersion, and drop that traffic. Only 0.6% of 40-byte substrings repeat more than 3 times in a minute.نبحث عن W ذات انتشار وتشتت عاليين ونحذف تلك الحركة. فقط 0.6% من السلاسل بطول 40 بايت تتكرر أكثر من 3 مرات في الدقيقة.

Challengesالتحديات

  • Computation: at 1 Gbps you have about 12 µs per packet, at 10 Gbps 1.2 µs; every byte must be inspected and memory references dominate.الحوسبة: عند 1 جيجابت تملك حوالي 12 ميكروثانية لكل حزمة، وعند 10 جيجابت 1.2 ميكروثانية؛ ويجب فحص كل بايت والذاكرة هي العائق الأكبر.
  • State: on a fully loaded 1 Gbps link a naive implementation can consume 100 MB/s for the table.الحالة (State): على رابط 1 جيجابت ممتلئ قد يستهلك التنفيذ الساذج 100 ميجابايت/ث للجدول.

8. Privilege Escalation and Executing Applications٨. رفع الصلاحيات وتنفيذ التطبيقات

An attacker gains network access with a non-admin account, then needs administrative privileges. Privilege escalation exploits design flaws, programming errors, bugs, and configuration oversights in the OS and applications. With those privileges the attacker can view sensitive information, delete files, or install viruses, trojans and worms.المهاجم يدخل الشبكة بحساب غير إداري ثم يحتاج صلاحيات إدارية. رفع الصلاحيات يستغل عيوب التصميم والأخطاء البرمجية والـ bugs وأخطاء الإعدادات في النظام والتطبيقات. وبهذي الصلاحيات يقدر يشوف المعلومات الحساسة ويحذف الملفات ويثبّت فيروسات وtrojans وديدان.

VERTICAL

Vertical escalationرفع عمودي

Gaining higher privileges than the existing ones.الحصول على صلاحيات أعلى من الموجودة.

HORIZONTAL

Horizontal escalationرفع أفقي

Acquiring the same level of privileges but assuming the identity of another user with similar privileges.الحصول على نفس المستوى من الصلاحيات لكن بانتحال هوية مستخدم آخر بصلاحيات مماثلة.

DLL hijackingاختطاف الـ DLL

  1. Most Windows applications do not use the fully qualified path when loading an external DLL; they search the directory they were loaded from first.أغلب تطبيقات ويندوز لا تستخدم المسار الكامل عند تحميل DLL خارجي، بل تبحث أولاً في المجلد الذي حُمّلت منه.
  2. The attacker places a malicious DLL in the application directory.المهاجم يضع DLL خبيث في مجلد التطبيق.
  3. The application loads the malicious DLL instead of the real one, and the attacker gains remote access.التطبيق يحمّل الـ DLL الخبيث بدل الحقيقي، فيحصل المهاجم على وصول عن بعد.

How to defend against privilege escalationكيف تدافع ضد رفع الصلاحيات

  • Restrict interactive logon privileges.تقييد صلاحيات تسجيل الدخول التفاعلي.
  • Use encryption to protect sensitive data.استخدام التشفير لحماية البيانات الحساسة.
  • Run users and applications on least privileges.تشغيل المستخدمين والتطبيقات بأقل صلاحيات.
  • Reduce the amount of code running with a particular privilege.تقليل الكود الذي يعمل بصلاحية معينة.
  • Implement multi-factor authentication and authorization.تطبيق مصادقة وتفويض متعددي العوامل.
  • Debug using bounds checkers and stress tests.التصحيح باستخدام bounds checkers واختبارات الضغط.
  • Run services as unprivileged accounts.تشغيل الخدمات بحسابات بلا صلاحيات.
  • Test OS and application coding errors and bugs thoroughly.اختبار أخطاء الكود والـ bugs في النظام والتطبيقات بدقة.
  • Implement privilege separation to limit the scope of errors and bugs.تطبيق فصل الصلاحيات لتحديد نطاق الأخطاء.
  • Patch the systems regularly.تحديث الأنظمة باستمرار.

Executing applicationsتنفيذ التطبيقات

Attackers execute malicious applications remotely on the victim's machine. This stage is called "owning" the system: gather information, gain unauthorized access, crack passwords, capture screenshots, install a backdoor. Typical tools: keyloggers, spyware, backdoors, crackers.المهاجم ينفذ برامج خبيثة عن بعد على جهاز الضحية. تسمى هذي المرحلة "owning" للنظام: جمع معلومات، وصول غير مصرّح، كسر كلمات المرور، التقاط لقطات الشاشة، تثبيت backdoor. الأدوات المعتادة: keyloggers وspyware وbackdoors وcrackers.

9. Rootkits in Depth٩. الـ Rootkits بالتفصيل

Rootkits hide their presence and the attacker's malicious activities, granting full access to the host now and in the future. They replace OS calls and utilities with modified versions. A typical rootkit includes backdoor programs, DDoS programs, packet sniffers, log-wiping utilities and IRC bots.الـ Rootkits تخفي وجودها ونشاط المهاجم، وتعطيه وصولاً كاملاً للجهاز حالياً ومستقبلاً. تستبدل استدعاءات النظام والأدوات بنسخ معدلة. وعادة يضم الـ rootkit برامج backdoor وDDoS وpacket sniffers وأدوات مسح السجلات وبوتات IRC.

  • Wrapping it in a special package like games.تغليفه في حزمة مثل الألعاب.

  • Launching a zero-day attack (privilege escalation, buffer overflow, Windows kernel exploitation).شن هجوم zero-day (رفع صلاحيات، buffer overflow، استغلال نواة ويندوز).

How a rootkit worksكيف يعمل الـ rootkit

HOOKING

Hookingالـ Hooking

Techniques that alter or augment the behavior of the OS or applications by intercepting function calls, messages or events. Code that handles them is a hook. Legitimate uses include debugging and extending functionality, but rootkits use it to fake API output that would reveal them.تقنيات تغيّر أو تضيف لسلوك النظام أو التطبيقات باعتراض استدعاءات الدوال أو الرسائل أو الأحداث. الكود الذي يعالجها يسمى hook. له استخدامات مشروعة كالـ debugging، لكن الـ rootkits تستخدمه لتزوير مخرجات الـ API التي قد تكشفها.

Example: the rootkit replaces the first 5 bytes of FindNextFile with a jmp to its own function.مثال: الـ rootkit يستبدل أول 5 بايتات من FindNextFile بأمر jmp إلى دالته.

DKOM

Direct Kernel Object Manipulationالتلاعب المباشر بكائنات النواة

A common Windows rootkit technique to hide processes, drivers, files and connections from Task Manager. It modifies the linked list of active processes (EPROCESS, FLINK/BLINK pointers) so the list wraps around the rootkit's process, unlinking it. This works because kernel modules and drivers have direct access to kernel memory.تقنية شائعة في ويندوز لإخفاء العمليات والتعريفات والملفات والاتصالات عن Task Manager. تعدّل القائمة المرتبطة للعمليات النشطة (مؤشرات FLINK وBLINK في EPROCESS) بحيث تتجاوز عملية الـ rootkit فتنفصل عنها. ممكن لأن وحدات النواة والتعريفات لها وصول مباشر لذاكرة النواة.

Integrity-basedCompares a snapshot of the file system, boot records or memory with a known trusted baseline.يقارن لقطة من نظام الملفات أو سجلات الإقلاع أو الذاكرة بخط أساس موثوق.
Signature-basedCompares characteristics of all system processes and executables with a database of known rootkit fingerprints.يقارن خصائص كل العمليات والملفات التنفيذية بقاعدة بيانات بصمات rootkits معروفة.

How to defend against rootkitsكيف تدافع ضد الـ Rootkits

  • Reinstall OS/apps from a trusted source after backing up critical data.أعد تثبيت النظام والتطبيقات من مصدر موثوق بعد نسخ احتياطي للبيانات المهمة.
  • Keep well-documented automated installation procedures.احتفظ بإجراءات تثبيت آلية موثقة جيداً.
  • Perform kernel memory dump analysis.حلّل dump لذاكرة النواة.
  • Harden the workstation or server.قوِّ حماية الجهاز أو السيرفر.
  • Educate staff not to download files from untrusted sources.وعِّ الموظفين بعدم تحميل ملفات من مصادر غير موثوقة.
  • Install network and host-based firewalls.ثبّت جدران حماية للشبكة وللجهاز.
  • Ensure trusted restoration media is available.وفّر وسائط استعادة موثوقة.
  • Update and patch OS and applications.حدّث النظام والتطبيقات.
  • Verify system file integrity regularly with cryptographically strong digital fingerprints.تحقق دورياً من سلامة ملفات النظام ببصمات رقمية قوية تشفيرياً.
  • Update antivirus and anti-spyware regularly.حدّث مضاد الفيروسات ومضاد التجسس باستمرار.
  • Avoid logging in with administrative privileges.تجنب تسجيل الدخول بحساب إداري.
  • Adhere to the least privilege principle.التزم بمبدأ أقل صلاحية.
  • Ensure the antivirus has rootkit protection.تأكد أن مضاد الفيروسات يحمي من الـ rootkits.
  • Do not install unnecessary applications; disable unused features and services.لا تثبّت تطبيقات غير ضرورية وعطّل الميزات والخدمات غير المستخدمة.
